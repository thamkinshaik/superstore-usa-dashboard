## 📊 Overview

This project is an interactive **Tableau dashboard** built to analyze Superstore USA sales data. It provides insights into sales performance, profit margins, and regional trends to support data-driven business decisions.

## 🔍 Key Features

- Sales and profit analysis across categories and sub-categories
- Regional performance comparison (Central, East, South, West)
- Trend analysis over time (monthly/yearly)
- Interactive filters for dynamic data exploration
- Profit margin breakdown by segment and region

## 🛠️ Tech Stack

- **Tool:** Tableau
- **Data:** Superstore USA Sales Dataset
- **File:** `superstore USA dashboard.twbx`

## 📁 How to Use

1. Download the `.twbx` file from this repository
2. Open it using [Tableau Public](https://public.tableau.com/) or Tableau Desktop
3. Explore the interactive filters and visualizations
